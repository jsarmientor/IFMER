Corte 1: Aplicaciones Web

Ponderación total: 33.3% de la nota final
Semanas 1 a 6 | Desarrollo de aplicaciones web, Frontend, Backend y Bases de Datos.

🎯 Objetivos del Corte

Durante este primer corte, el estudiante aprenderá a desarrollar aplicaciones web, comprendiendo la arquitectura cliente-servidor y el ecosistema de desarrollo moderno. Se cubrirán los fundamentos de Frontend con HTML, CSS y Bootstrap, y de Backend con PHP y bases de datos MySQL, culminando en la implementación de operaciones CRUD completas.

🚀 Entregable Final del Corte 1

Como proyecto final del primer corte, los estudiantes deberán entregar una Gestión de Inventario (CRUD) completamente funcional utilizando tecnologías web (Frontend y Backend). Este sistema deberá permitir el registro, consulta, actualización y eliminación de productos o pacientes en la base de datos.

Para apoyar el desarrollo del entregable, descargue los siguientes recursos obligatorios:

  • 📄 Guía de Desarrollo WEB (PDF) - Instructivo paso a paso para la construcción del aplicativo web.
  • 📊 Base de Datos Base (Excel) - Datos iniciales para la estructuración y migración de la base de datos a MySQL.

Estos documentos serán fundamentales para las clases prácticas y la evaluación de la Semana 6.

📅 Contenido Semana por Semana

🟦 Semana 1 - Clase 01: Jerarquía del Conocimiento y Salud 4.0

  • Conceptos: Jerarquía del conocimiento (Modelo DIKW), Salud 4.0 y fundamentos básicos de programación.
  • Práctica: Programando el triaje (El Ciclo DIKW Aplicado en código).
  • Recursos: Ver Guía de Clase | 💻 Ver Presentación Diapositivas

🟦 Semana 2 - Clase 02: Metodologías Ágiles y Paradigma Cliente-Servidor en Salud

  • Conceptos: Metodologías ágiles (Scrum), roles, paradigma cliente-servidor, conceptos de Frontend/Backend y CRUD.
  • Práctica: Diseño del diccionario de datos clínicos basado en la Resolución 866 de 2021.
  • Recursos: Ver Guía de Clase | 💻 Ver Presentación Diapositivas

🟦 Semana 3 - Clase 03: Desarrollo Backend y Base de Datos (PHP y MySQL)

  • Conceptos: Programación del lado del servidor con PHP y modelado de bases de datos relacionales.
  • Práctica: Conexión de la aplicación a MySQL (conexion.php).
  • Recursos: Ver Guía de Clase | 💻 Ver Presentación Diapositivas

🟦 Semana 4 - Clase 04: Operaciones CRUD (Crear, Leer, Actualizar, Eliminar)

  • Conceptos: Implementación de acciones CRUD (actualizar.php, eliminar.php, etc.).
  • Práctica: Integración final del Backend con la interfaz Frontend.
  • Recursos: Ver Guía de Clase | 💻 Ver Presentación Diapositivas

🟦 Semana 5 - Clase 05: Consolidación de Conceptos: Integración y Despliegue

  • Conceptos: Integración completa de la aplicación, pruebas y despliegue local.
  • Práctica: Taller integrador de desarrollo web.
  • Recursos: Ver Guía de Clase | 💻 Ver Presentación Diapositivas

🟦 Semana 6 - Clase 06: Evaluación Corte 1

  • Evaluación Sumativa: Entrega de la aplicación web desarrollada y evaluación teórica.
  • Recursos: Ver Guía de Evaluación
