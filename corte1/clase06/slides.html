De un Excel del hospital a una aplicación web con CRUD

La cadena de hoy

Excel real → Auditoría → Diccionario → Tabla MySQL → CRUD en PHP

El Excel no se copia: se audita, se decide y se diseña.

Si el diccionario está mal, la aplicación está mal.

La fuente: BD.xlsx

Inventario del Hospital Universitario Nivel III (institución de alta complejidad)

  • 67 equipos × 31 columnas
  • Salas de cirugía, UCI adulto y coronaria, imagenología, unidad renal
  • Hojas: Listado Equipos, Ficha Tecnica, MPP, Predicitivo

Y viene con todos los problemas de un archivo real.

Lo que esconde ese archivo

  • Dos columnas se llaman igual: UBICACIÓN y UBICACIÓN
  • PLACA NUEVA está llena en 17 de 67 equipos
  • FECHA DE INSTALACION y FECHA DE COMPRA: 100 % vacías
  • FECHA DE FABRICACION solo trae el año
  • PESO: 120gr, 12Kg, 1,7Tn — tres unidades
  • CORRIENTE: 0,5A, 2.2A, 300mA — coma y punto
  • Diagnostico vs diagnostico vs DIAGNOSTICO
  • CONDICIONES DE TRABAJO: un solo valor en las 67 filas

Las 4 decisiones posibles

Cuándo Ejemplo
🗑️ Descartar Vacía o constante FRECUENCIA DE ALIMENTACION
✅ Conservar Atómico, texto libre MARCA
✂️ Dividir Valor + unidad, rango 0 - 43°C
🔗 Normalizar Lista cerrada CLASIFICACION BIOMEDICA

La pregunta que decide todo

“¿Qué consulta quiero poder hacer con este dato?”

“¿Cuántos equipos de soporte de vida hay en la UCI?” → hay que normalizar

“¿Cuáles equipos pesan más de 100 kg?” → hay que dividir y unificar unidades

“¿Cuántos equipos trabajan a 60 Hz?” → nadie la hace, y todos son iguales → descartar

Tipificar no es cosmético

ActivoFijo como INT

El equipo E000774 no se puede registrar.

Perdimos un equipo del hospital por elegir mal un tipo de dato.

Del diccionario al SQL

CREATE TABLE inventario (
  IdEquipo          INT AUTO_INCREMENT PRIMARY KEY,
  ActivoFijo        VARCHAR(15) NOT NULL,
  NombreEquipo      VARCHAR(80) NOT NULL,
  AnioFabricacion   YEAR        NULL,
  PesoKg            DECIMAL(8,3) NULL,
  IdServicio        INT         NOT NULL,
  IdClasifRiesgo    INT         NOT NULL,
  EstadoEquipo      TINYINT(1)  NOT NULL DEFAULT 1,
  CONSTRAINT uq_activo UNIQUE (ActivoFijo),
  CONSTRAINT fk_serv FOREIGN KEY (IdServicio)
      REFERENCES servicios(IdServicio)
);
